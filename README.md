# MNIST-IRIS-RAVDESS

A collection of deep learning and machine learning notebooks exploring three classic datasets.

## Goal

The goal of this project is to apply and compare machine learning and deep learning techniques on three well-known datasets:

- **MNIST** – Handwritten digit recognition (0–9) using neural networks.
- **IRIS** – Flower species classification using traditional ML and simple neural networks.
- **RAVDESS** – Speech emotion recognition from the Ryerson Audio-Visual Database of Emotional Speech and Song.

Each notebook walks through data loading, preprocessing, model building, training, evaluation, and result analysis.

## Datasets

| Dataset  | Task                         | Type              |
|----------|------------------------------|-------------------|
| MNIST    | Image classification (digits)| Supervised / CNN  |
| IRIS     | Tabular classification       | Supervised / MLP  |
| RAVDESS  | Audio emotion recognition    | Supervised / DNN  |
